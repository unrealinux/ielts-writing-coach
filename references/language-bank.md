# 语言升级库

批改时用于两类场景：① 把考生的弱表达替换为目标分表达；② 给出可迁移的词块（不是模板句）。

## 一、升级替换表

| 弱表达（5–6 分特征） | 目标分表达（7+） | 注意 |
|---|---|---|
| a lot of / lots of | a substantial number of / a considerable proportion of / numerous | 学术语域 |
| more and more | a growing number of / an increasing proportion of / rising | — |
| very important | crucial / critical / pivotal / of paramount importance | 后两个偏正式，勿滥用 |
| very big | substantial / significant / considerable / pronounced | 修饰变化幅度时用 pronounced |
| good | beneficial / advantageous / effective / conducive to | `conducive to` 后接名词 |
| bad | detrimental / harmful / adverse / counterproductive | adverse 多修饰 effect/impact |
| get | obtain / acquire / receive / secure | 视语义选 |
| things | factors / aspects / elements / considerations | things 在学术文中基本禁用 |
| people | individuals / citizens / the public / residents（按语境） | people 不必全删，但重复时替换 |
| kids | children / young people / adolescents | — |
| think | believe / argue / maintain / contend / hold the view that | contend/maintain 偏正式 |
| say | state / assert / point out / note | — |
| show | demonstrate / illustrate / indicate / reveal | Task 1 高频 |
| make (a decision) | take / reach (a decision) | 搭配 |
| do (research) | conduct / carry out (research) | 搭配 |
| solve | address / tackle / alleviate / mitigate | alleviate/mitigate 指缓解非解决 |
| cause | give rise to / lead to / result in / bring about | 后接结果 |

| but | however / nevertheless / whereas / while | 句中 vs 句首标点不同 |

| so | therefore / consequently / as a result / hence | — |
| I think | In my view / From my perspective / I would argue that | 学术文中避免 I think 反复出现 |

| In conclusion | In conclusion / To conclude / On balance | 不要用 `At last` |

## 二、Task 1 数据描述词块

**趋势**（动词 + 副词 / 形容词 + 名词 两种句法都要会）

- 上升：`rose sharply` / `experienced a sharp rise` / `saw a steady increase`
- 下降：`fell steadily` / `underwent a steady decline` / `recorded a slight drop`
- 波动：`fluctuated around 40%` / `showed considerable fluctuation`
- 平稳：`remained stable at roughly 30%` / `levelled off` / `plateaued at`
- 峰值/谷值：`peaked at 85% in 2010` / `reached a low of 12%` / `bottomed out at`
- 幅度：`increased by 15 percentage points` / `doubled` / `halved` / `tripled` / `was twice as high as`

**比较与分组**

- `X was the largest category, accounting for just under half of the total.`
- `Y, by contrast, made up only a small fraction.`
- `While A rose markedly, B and C both declined.`
- `The two groups followed broadly similar patterns.`
- `A overtook B in 2005 and remained the leading category thereafter.`

**概数与不确定性**（避免假精确）

- `approximately` / `roughly` / `just under` / `just over` / `around` / `slightly more than`
- `a negligible proportion` / `a substantial majority` / `a small minority`
- 未来：`is expected to` / `is projected to` / `is likely to`

**流程图**

- `The process begins with ...` → `Once X has been ..., it is then ...` → `The final stage involves ...`
- 被动：`the raw materials are crushed and then transported to ...`
- 循环：`... , after which the cycle begins again.`

**地图**

- 方位：`to the north of` / `on the eastern edge of` / `adjacent to` / `in the south-west corner`
- 变化：`was demolished and replaced by` / `was converted into` / `was extended` / `gave way to`
- `The most striking change is that ...`

## 三、Task 2 论证词块（结构 > 套句）

**引言**

- 改写题干：`While some maintain that ..., others argue that ...`
- 立场：`This essay argues that ..., primarily because ...` / `I largely agree with this view, although ...`
- ❌ 避免：`With the development of society and economy, ...`、`Nowadays, ... is becoming more and more popular.`

**主体段中心句**

- `The primary reason for this is that ...`
- `The most compelling argument in favour of X concerns ...`
- `Critics of this approach point to ...`
- `This is particularly true of ...`

**展开论证**

- 机制：`This is because ... , which in turn ...`
- 条件：`Provided that ... , the effect is likely to be ...`
- 让步：`Although this may hold in the short term, ...`
- 例证：`A clear illustration of this is ...` / `In countries such as ..., ...`
- 回扣：`This demonstrates why ... is necessary.`

**结论**

- `In conclusion, although ..., the evidence suggests that ...`
- `On balance, the benefits of X appear to outweigh its costs, chiefly because ...`
- ❌ 不要在结论引入新论点，不要只说 `In conclusion, I agree.`

## 四、衔接手段（少用连接词，多用指代与词汇衔接）

| 类型 | 手段 | 示例 |
|---|---|---|
| 指代 | this / these / such / the former / the latter | `Such measures, however, are costly.` |
| 词汇衔接 | 同义替换、上下义词 | `car use` → `private vehicles` → `this mode of transport` |
| 重复关键名词 | 有意重复以维持话题 | `the policy ... this policy ... the policy's effects` |
| 逻辑连接词 | 适度使用 | 每 3–4 句一个为宜，不要每句一个 |

**判断标准**：如果把文中所有 `Moreover/Furthermore/In addition` 删掉，逻辑是否还成立？如果不成立，说明真正的逻辑关系没写出来，靠连接词掩盖。

## 五、使用纪律

1. **不要把这些词块当模板塞进作文**。批改时给出的是"这句话在你这个语境下的更好说法"，不是可背诵段落。
2. **升级词必须与语境匹配**。`mitigate` 不能替换 `solve`（语义不同）；`paramount` 用错场合比 `very important` 更扣分。
3. **替换不等于越长越好**。`due to the fact that` 不如 `because`；`in the not too distant future` 不如 `soon`。
4. 考生已用对的表达**不要改**。批改只动有问题的部分。
